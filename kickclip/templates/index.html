YouTube hesabını bağla

Bir kerelik kurulum (~10 dk, ücretsiz). Google, video yükleyen her uygulamadan bir "istemci dosyası" ister:

  1. console.cloud.google.com'a YouTube kanalının olduğu hesapla gir → Yeni proje → ad: KickClip → Oluştur.
  2. YouTube Data API v3 sayfasında Etkinleştir.
  3. Google Auth Platform → Başlayın → uygulama adı KickClip, e-postan → Kitle: Harici → Bitir.
  4. Kitle sekmesi → Test kullanıcıları → Kullanıcı ekle → kendi Gmail adresin → Kaydet.
  5. İstemciler → İstemci oluştur → tür: Masaüstü uygulaması → Oluştur → JSON'u indir.
  6. İndirdiğin dosyayı buraya yükle:

Google sayfasında "Google bu uygulamayı doğrulamadı" uyarısı çıkarsa normal (uygulamayı sen oluşturdun): Gelişmiş → KickClip'e git → izinleri işaretle → Devam.

Canlı yayın, VOD veya klip linki olabilir.
